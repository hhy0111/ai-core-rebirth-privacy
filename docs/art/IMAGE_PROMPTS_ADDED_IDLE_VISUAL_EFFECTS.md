# 추가 이미지 프롬프트 - 방치형 보는맛/업그레이드 시각 성장

이 파일은 기존 프롬프트 파일을 유지한 채 추가로 제작할 이미지 목록입니다. 목표는 메인 화면에서 행성을 계속 보고 싶게 만드는 시각 성장 레이어를 확보하는 것입니다.

## 공통 스타일

- 2D top-down mobile idle game asset, cartoon neon sci-fi, bright vivid colors, polished casual game quality
- Clear silhouette at small mobile size, high contrast, readable at 1080x1920 portrait canvas
- No text, no logo, no watermark, no UI frame unless specified
- Transparent PNG for effect/sprite assets
- Background assets should leave the center readable for a large planet object
- Avoid dark muddy colors, realistic horror, tiny noisy details, photorealistic rendering

## 구현 우선순위

1. 현재 코드에는 우선 절차적 이펙트로 업그레이드 레벨별 링, 위성, 표면 노드, 자원 흐름을 구현한다.
2. 이미지가 생성되면 위 파일명을 기준으로 `image/` 폴더에 넣고, 같은 역할의 절차적 도형을 이미지 레이어로 교체한다.
3. 행성별 배경 이미지는 기존 추가 프롬프트 파일을 유지하고, 이 파일은 메인 행성 성장 효과에만 집중한다.
