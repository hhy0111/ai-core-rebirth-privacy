# 방치형 보는맛 개선 기획

작성일: 2026-05-09  
목표: 플레이어가 게임 화면을 켜두고 싶고, 다음 업그레이드를 누르면 행성이 더 화려해질 것이라는 기대를 갖게 만든다.

## 1. 문제 정의

현재 화면은 행성, 자원 UI, 업그레이드 패널의 기본 구조는 갖췄지만 방치형 게임의 핵심인 "보는맛"이 약하다.

문제:

* 자동 생산이 되고 있어도 화면 변화가 작다.
* 업그레이드 후 수치는 오르지만 행성이 얼마나 강해졌는지 시각적으로 남지 않는다.
* 행성을 계속 보고 있을 이유가 부족하다.
* 이펙트가 일회성에 가까워 성장 누적감이 약하다.

## 2. 핵심 방향

### 2-1. 행성을 성장 장식판으로 만든다

행성은 단순 배경 오브젝트가 아니라 플레이어 성장의 결과가 쌓이는 중심 오브젝트가 되어야 한다.

업그레이드가 쌓일수록 다음 요소가 늘어난다.

* 궤도 링 수
* 주변 위성/드론 수
* 표면 발광 노드 수
* 에너지 입자 밀도
* 자원 흐름 라인
* 단계별 복원 오라

### 2-2. 성장 변화는 3단계로 보이게 한다

순간 변화:

* 업그레이드 버튼을 누르면 레벨업 폭발 이펙트 발생
* 행성에 짧은 파동이 퍼진다

영구 변화:

* 업그레이드 레벨 합계가 올라갈수록 행성 주변 장식이 상시 증가
* 생산 종류별 장식 색이 달라진다

방치 변화:

* 켜두면 자원 입자, 궤도 위성, 표면 노드가 계속 움직인다
* 완성 단계에 가까울수록 움직임이 많아진다

## 3. 시각 성장 레이어

### 3-1. 복원 오라

조건:

* 행성 복원도와 단계에 비례

표현:

* 붕괴: 약한 청록 오라, 붉은 균열 잔광
* 활성화: 청록 링과 표면 노드 증가
* 성장: 초록 생명 오라와 작은 발광 점 증가
* 완성: 금색/청록 안정 링과 고밀도 입자

### 3-2. 업그레이드 궤도 링

조건:

* 현재 행성 업그레이드 4종의 레벨 합계

표현:

* 레벨 합계 0~3: 기본 링
* 4~9: 얇은 보조 링 1개
* 10~19: 반대 방향 링 1개 추가
* 20~39: 위성/드론 2~4개
* 40 이상: 궤도 네트워크와 금색 희귀 입자 강화

### 3-3. 생산 타입별 표식

에너지 생산:

* 청록 위성, 전력선, 빠른 회전 입자

바이오매스 생산:

* 초록 발광 씨앗, 행성 표면의 생명 점, 느린 생장 파동

AI 데이터 생산:

* 금색 메모리 조각, 작은 홀로그램 노드, 데이터 궤적

복원 속도:

* 흰색/청록 복원 파동, 표면 균열 봉합선

오프라인 보상:

* 느린 외곽 저장 궤도, 안정적인 점멸 노드

터치 보상:

* 코어 터치 영역 주변 반응 링 강화

## 4. 플레이 욕구 설계

### 4-1. 업그레이드를 누르고 싶은 이유

업그레이드 전:

* 현재 효과/다음 효과 표시
* 행성은 현재 시각 레이어를 보여줌

업그레이드 후:

* 즉시 레벨업 폭발
* 행성 주변 링/입자/위성 밀도가 조금 증가
* 특정 레벨 구간에서 눈에 띄는 새 장식이 추가

결과:

* 플레이어가 "다음 레벨을 누르면 더 화려해진다"는 기대를 갖는다.

### 4-2. 계속 보고 싶은 이유

방치 중:

* 자원 입자가 행성에서 흘러나온다
* 위성이 궤도를 돈다
* 표면 노드가 점멸한다
* 가끔 터치 가능한 오브젝트가 지나간다

결과:

* 화면이 정적인 메뉴가 아니라 살아 있는 복원 장치처럼 느껴진다.

## 5. MVP 구현 범위

이번 개발에서 바로 구현할 것:

* 업그레이드 레벨 합계 기반 행성 상시 이펙트
* 단계/복원도 기반 오라 강화
* 생산 타입별 색상 입자와 궤도 장식
* 현재 행성 업그레이드가 높을수록 위성/노드 수 증가
* `render_game_to_text`에 시각 성장 강도 출력

이미지 추가 후 구현할 것:

* 행성별 배경 12종 적용
* 터치 가능한 지나가는 우주선/생명체 적용
* 보상 획득 전용 이미지 이펙트 적용
* 업그레이드 타입별 작은 장식 스프라이트 적용

## 6. 성공 기준

* 업그레이드 전후 행성 주변 시각 밀도 차이가 보인다.
* 1~3분 동안 화면을 켜두면 계속 움직이는 요소가 있다.
* 행성 단계가 올라갈수록 "살아난다"는 인상이 강해진다.
* 업그레이드를 많이 한 행성과 덜 한 행성의 화면 차이가 보인다.
* 수치 UI를 보지 않아도 성장감이 전달된다.

## 7. 밸런스 원칙

* 보는맛은 강화하지만 게임 진행 속도는 과도하게 올리지 않는다.
* 시각 효과는 업그레이드 욕구를 만들되 결제 압박으로 연결하지 않는다.
* 너무 밝아져 UI 가독성을 해치면 안 된다.
* 하위 기기에서도 문제 없도록 한 화면의 상시 입자는 제한한다.
